# Translate-v2
نسخه PWA مترجم عصبی
این پروژه یک وب‌اپ قابل نصب (PWA) برای ترجمه فارسی ↔ انگلیسی است.
انتشار و نصب
تمام محتویات این پوشه را روی یک میزبان وب با HTTPS بارگذاری کنید (برای نمونه GitHub Pages یا هاست شخصی).
آدرس سایت را با Chrome در اندروید باز کنید.
از منوی مرورگر گزینه «Install app / نصب برنامه» یا «Add to Home screen / افزودن به صفحه اصلی» را بزنید.
بار اول، در حالی که اینترنت متصل است، صبر کنید مدل فارسی→انگلیسی بارگذاری شود. سپس یک ترجمه انگلیسی→فارسی نیز انجام دهید تا مدل دوم دریافت شود.
آفلاین
Service Worker فایل‌های برنامه و درخواست‌های GET موفق را برای استفاده بعدی در Cache API ذخیره می‌کند. کتابخانه Transformers.js و فایل‌های مدل از CDN دریافت می‌شوند و ذخیره/بازیابی آفلاین فایل‌های حجیم وابسته به سیاست کش مرورگر، فضای آزاد و رفتار CDN است؛ بنابراین آفلاین بودن کامل و همیشگی تضمین‌شده نیست. پس از نصب، هر دو جهت را در حالت آنلاین آزمایش کنید و سپس حالت پرواز را برای بررسی واقعی امتحان کنید.
نکات فنی
نیازمند HTTPS یا localhost برای Service Worker و نصب PWA
زبان رابط: فارسی
مدل‌ها: Xenova/opus-mt-fa-en و Xenova/opus-mt-en-fa
این نسخه به سرور ترجمه وابسته نیست، اما برای دانلود اولیه مدل به اینترنت نیاز دارد.
